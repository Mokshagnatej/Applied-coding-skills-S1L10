## 💡 Master Algorithmic Pattern Playbook

<details>
<summary><b>1. Dutch National Flag & 3-Way Partitioning (Module 01)</b></summary>
<br/>

**Application:** Partition an array in-place into three contiguous segments (e.g. `0`s, `1`s, `2`s) in $\mathcal{O}(N)$ time and $\mathcal{O}(1)$ space.
- Maintain three pointers: `low = 0`, `mid = 0`, `high = n - 1`.
- If `nums[mid] == 0`: Swap `nums[low]` and `nums[mid]`, advance both `low++` and `mid++`.
- If `nums[mid] == 1`: Simply advance `mid++`.
- If `nums[mid] == 2`: Swap `nums[mid]` and `nums[high]`, shrink `high--` (do **not** advance `mid` as the swapped value must be evaluated).

```java
int low = 0, mid = 0, high = nums.length - 1;
while (mid <= high) {
    if (nums[mid] == 0) {
        swap(nums, low++, mid++);
    } else if (nums[mid] == 1) {
        mid++;
    } else {
        swap(nums, mid, high--);
    }
}
```
</details>

<details>
<summary><b>2. Floyd's Cycle Detection & Fast/Slow Pointers (Module 02)</b></summary>
<br/>

**Application:** Detect circular loops in linked lists, find exact collision entrance nodes, and locate the midpoint in $\mathcal{O}(1)$ memory.
- **Midpoint Finding:** `fast` moves 2 steps, `slow` moves 1 step. When `fast == null || fast.next == null`, `slow` points at the middle node.
- **Cycle Entrance:** Once `slow` and `fast` meet inside the cycle, reset `slow = head`. Move both pointers 1 step at a time; the node where they meet again is the exact cycle entry node.

```java
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) {
        ListNode ptr = head;
        while (ptr != slow) {
            ptr = ptr.next;
            slow = slow.next;
        }
        return ptr; // Cycle start node
    }
}
return null;
```
</details>

<summary><b>3. In-Place Linked List Reversal & K-Group Manipulation (Module 02)</b></summary>
<br/>

**Application:** Invert pointer directions without allocating new nodes or auxiliary collections.
- Standard 3-pointer slide (`prev`, `curr`, `next`):

```java
ListNode prev = null, curr = head;
while (curr != null) {
    ListNode next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
}
return prev;
```

- **K-Group Reversal:** Check if $k$ nodes exist ahead; if yes, reverse that segment, recursively/iteratively link the next segment to the previous tail, and update boundary references.
</details>

<summary><b>4. Monotonic Decreasing Stack for Next Greater Elements (Module 03)</b></summary>
<br/>

**Application:** Compute the next greater, next smaller, or daily temperature span for every element in amortized $\mathcal{O}(N)$ time.
- The stack stores indices such that values are strictly decreasing from bottom to top.
- When encountering an element greater than `nums[stack.peek()]`, pop all smaller elements—their "next greater" is the current element!

```java
int[] result = new int[nums.length];
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
        int prevIndex = stack.pop();
        result[prevIndex] = i - prevIndex; // Or nums[i] depending on requirement
    }
    stack.push(i);
}
```
</details>

<summary><b>5. Monotonic Deque for Sliding Window Extrema (Module 04)</b></summary>
<br/>

**Application:** Find the maximum or minimum element in every sliding window of size $k$ in overall $\mathcal{O}(N)$ linear time.
- Use a `Deque<Integer>` storing indices.
- Before adding index `i`, remove all smaller elements from the back (`removeLast()`) because they can never be the maximum again.
- Evict the front element if its index is outside the window (`getFirst() == i - k`).
- The front of the deque (`peekFirst()`) always holds the maximum of the current window.

```java
Deque<Integer> deque = new ArrayDeque<>();
for (int i = 0; i < nums.length; i++) {
    while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
        deque.pollLast();
    }
    deque.offerLast(i);
    if (deque.peekFirst() == i - k) {
        deque.pollFirst();
    }
    if (i >= k - 1) {
        result[i - k + 1] = nums[deque.peekFirst()];
    }
}
```
</details>

<summary><b>6. Hierarchical Breadth-First Search (Tree BFS) (Module 04)</b></summary>
<br/>

**Application:** Traverse binary trees level-by-level in $\mathcal{O}(N)$ time while maintaining explicit level grouping.
- Use a `Queue<TreeNode>` initialized with `root`.
- Snapshot `int size = queue.size()` at the start of each level loop.
- Process exactly `size` nodes for that level and enqueue their valid child pointers.

```java
Queue<TreeNode> queue = new LinkedList<>();
queue.offer(root);
while (!queue.isEmpty()) {
    int levelSize = queue.size();
    List<Integer> currentLevel = new ArrayList<>();
    for (int i = 0; i < levelSize; i++) {
        TreeNode curr = queue.poll();
        currentLevel.add(curr.val);
        if (curr.left != null) queue.offer(curr.left);
        if (curr.right != null) queue.offer(curr.right);
    }
    result.add(currentLevel);
}
```
</details>
