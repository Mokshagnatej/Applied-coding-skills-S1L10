## 🎯 Learning Objectives

- **Two Pointer Techniques:** Opposite-end convergence, in-place element swapping, and sliding window boundaries.
- **Partitioning Algorithms:** Dutch National Flag 3-way partitioning in $O(N)$ time and $O(1)$ space.
- **Prefix Sums:** Precomputing cumulative sums for $O(1)$ range queries and difference balances.
- **Binary Search:** Logarithmic search on sorted collections with exact boundary condition handling.
